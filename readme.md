# ⚙️ Getting Started

## Clone Repository

```bash
git clone https://github.com/Aayansh-singh-24/She-ield.git

cd She-ield
```

---

## Backend Setup

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```

Backend Server

```
http://127.0.0.1:8000
```

Swagger Documentation

```
http://127.0.0.1:8000/docs
```

ReDoc Documentation

```
http://127.0.0.1:8000/redoc
```

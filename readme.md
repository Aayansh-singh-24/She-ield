# ⚙️ Local Setup

## Clone the Repository

```bash
git clone https://github.com/yourusername/sheield.git

cd sheield
```

---

## Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```

Backend

```text
http://127.0.0.1:8000
```

Swagger

```text
http://127.0.0.1:8000/docs
```
